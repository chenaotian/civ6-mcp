## 商路

依据安装目录内 `Base/Assets/UI/Choosers/TradeRouteChooser.lua`。风云变幻 `InGame.xml` 仍加载此实现，无资料片替换文件。

- 第 77–91 行：起点为 `Cities.GetCityInPlot(unitX,unitY)`，不能用工作地块归属城市代替。
- 第 456–489、810–822 行：本方优先枚举城市，检查 `CanStartOperation(MAKE_TRADE_ROUTE,nil,params)`，并要求 `GetTradeRoutePath` 非空。操作检查单独成功不代表城市属于菜单。
- 第 759–768、826–835 行：选择来自菜单目的地，提交使用正常 `RequestOperation`。MCP 在提交时重做完整资格检查。
- 第 1057–1076 行：自有贸易单位、清醒且有移动力。忙碌或无移动力时不生成可执行路线。

原版 Lua 没有额外的 `IsVisible`、`IsRevealed`、`HasMet` 城市过滤；探索等引擎限制交给原版同一资格判断，不另猜引擎内部规则。内部枚举不等于导出：失败候选的名字、坐标、数量、路径及产出不会返回。

允许字段为目的地名字／坐标（坐标随动作提供），以及选中路线在菜单中显示的收益总值。`TradeSupport.lua` 第 36–146 行分别累计起点和终点的 PotentialRoute、Path、Modifiers，国际路线按收益接收方的倍率处理正收益。原始路线、门户数组及外国城市完整状态不返回。

## 间谍

风云变幻使用 `DLC/Expansion2/UI/Replacements/EspionageChooser_Expansion1.lua`，它 include 基础 chooser 并替换城市列表。资料片规则与基础规则分别核对，未知规则集不猜测。

- 资料片替换文件第 27–36 行：外交状态有效、非同盟、排除其他同队玩家、非自由城市；风云变幻列表可包含城邦。
- `Base/Assets/UI/Choosers/EspionageChooser.lua` 第 421–428 行：城市中心须已探索；不要求当前可见。
- 第 190–240 行：自有城市仅反间谍，外城仅固定白名单中的 `OFFENSIVESPY` 任务；调用 `CanStartOperation(spy,hash,cityPlot,false,true)` 生成菜单目标。进攻任务仅在没有有效 PLOTS 时回退城市中心。
- 第 246–283 行：反间谍目标还必须与当前城市的区域对应。目的地预览中的任务按钮禁用。
- 第 645–654 行：可执行任务的城市来自间谍当前位置。远城任务允许预览，但没有可执行动作，不能靠传入远处坐标执行。
- 第 606–618 行：派遣使用经过菜单城市筛选的 `SPY_TRAVEL_NEW_CITY` 正常检查和请求。
- `EspionagePopup.lua` 第 350–367、472–477 行：普通进攻任务接受时不发送目标坐标，只提交任务 Hash；反间谍使用已核实的区域坐标。

任务目标来自原版返回的 PLOTS，不对任意输入坐标调用世界对象查询。菜单例外只允许对应任务信息，不能据此返回隐藏地块的资源、地形、单位或完整城市对象。

## 双重过滤与分页

Lua 先核对自有单位与原版菜单资格，之后才添加公开字段。Python 使用独立 `scope="menu"` 证明，绑定菜单类别、来源、本地玩家和单位；动作须属于同一菜单与单位。证明不满足时整条丢弃，额外原始字段永远不复制。

四个菜单查询保持原工具和参数名。目的地查询从 `offset=0` 开始，每页最多 64 个合格条目，使用 `next_offset` 继续，`-1` 结束；索引基于公开菜单条目，不暴露失败候选数量。动作重新校验菜单资格，不依赖上次列表缓存。
