# 已确认的玩家信息规则

2026-10-22 用户逐项确认 P01～P07；2026-10-27 补充确认 P08～P10。以下作为本项目的公平性规则，无需重复确认。
新接口仍须验证实际游戏 API 与测试；规则允许公开不等于开放任意调试读取。

| 编号 | 用户确认 | 实现规则 |
| --- | --- | --- |
| P01 | 原有迷雾处理没有问题。 | 保留已探索/当前可见标签；不可见时不读实时详情，不维护跨存档记忆。 |
| P02 | 可见敌城的人口、城防血量、宗教、区域/建筑、当前生产均可返回。 | 仅市中心当前可见时返回这些字段。区域/建筑仅返回类型，不借机泄露雾内坐标。 |
| P03 | 隐形单位有自己的显形条件，如相邻单位、海军袭击者、驱逐舰探测；按游戏手册规则。 | 使用原游戏 UI 的 `PlayersVisibility[me]:IsUnitVisible(unit)`，在地块可见后再次逐单位检查。引擎判定包含实际能力、距离和状态；不自行硬编码潜艇名单。 |
| P04 | 未解锁的战略资源不显示，解锁后正常显示。 | 保留地块可见＋玩家资源层＋玩家 `IsResourceVisible` 验证；不暴露底层资源类型或数量。不确定的地块产出字段继续省略。 |
| P05 | 文明总数量已知；身份仅在遇见后公开。 | 总数定义为曾参与游戏的主要文明（含自己及已灭亡文明，不含城邦/蛮族）；未知文明不返回 ID、名字、领袖或属性。 |
| P06 | 所列外交面板信息可以显示。 | 已接触文明可返回金币、科技/文化、军力、分数及公开胜利汇总；议程仍匹配原 UI 的情报可见性门槛，不返回“隐藏议程”的真实内容。 |
| P07 | 无额外模组，仅风云变幻和迭起兴衰。 | 目标是单人、标准规则的 Gathering Storm + Rise and Fall 内容；不按自定义模组扩展权限。 |
| P08 | 贸易菜单实际提供的选项可以返回并选择，即使目的地当前在战争迷雾中。 | 仅允许本玩家商人正常菜单实际提供的目的地、菜单信息和选择；底层接口若返回菜单之外的候选或字段，必须过滤。不能借此读取雾中城市的其他实时状态、沿途隐藏地图或扩大普通地图查询权限。 |
| P09 | 间谍菜单实际提供的选项可以返回并选择，即使目标当前在战争迷雾中。 | 仅允许本玩家间谍正常菜单实际提供的目标城市／区域、任务信息和选择；底层接口若返回菜单之外的候选或字段，必须过滤。不能借此读取其他隐藏城市、区域、单位或任务状态。 |
| P10 | 明确接受任意 Lua 无法自动强制过滤隐藏信息，授权继续实现备用接口；仅在常规接口无法解决时使用，仍禁止作弊、读取隐藏信息或改动电脑环境。 | `run_lua` 明确标为备用，必填真实原因与已尝试工具；身份/会话前检、一次执行、无自动重放、输出有界。任意代码没有自动公平过滤或沙箱保证；调用方必须遵守原有玩家信息边界。不能把此授权解释为允许高权限取数、作弊或电脑环境操作。 |

P08～P09 是针对原版菜单的有限授权，普通地图仍执行 P01～P05；不能把“已遇见文明”或底层操作接口接受请求等同于“菜单实际提供该选项”。发现候选和提交动作都必须满足相应菜单条件。规则确认不表示实现及实机验收已经完成，工程状态另行记录。

如果新增字段的公开条件无法核实，继续记录并默认省略。战斗/外交动作的开发和权限验证与读取权限分开处理。
