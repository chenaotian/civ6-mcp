# API 权限与验收

本项目独立实现常规接口的白名单检查，没有导入现有 civ6-mcp 的工具注册器，也没有承诺覆盖游戏所有 Lua API。

`query_manual` 是独立的离线静态资料接口，默认查阅官方简中文明百科文本索引，三本原 PDF 仅作显式参考。只读固定目录中校验通过的资料，不访问对局、FireTuner、存档或日志，也不改变观察令牌。静态通用规则/文明说明不代表当前对局已发现或启用对应内容；文本可能缺少动态数值，当前正常菜单与引擎规则优先。详见 [游戏手册](GAME_MANUAL.md)。

用户于 2026-10-27 明确接受任意 Lua 无法自动强制过滤隐藏信息的限制，授权引入 `run_lua` **备用接口，只有游戏中当前已提供的常规接口无法解决的问题才可以使用**。0.4.2 实现包含必填原因、已尝试游戏常规工具声明、前检及目标上下文的单人本地玩家/会话检查、一次执行、不自动重试及普通状态失效，已通过离线合并验证，实机验证仍待新对局。服务验证参数和身份，不证明声明的尝试确实发生，也不自动证明脚本必要或公平；授权来自用户本次明确同意，不能由调用方自行扩大。

**下表的内容过滤和动作白名单适用于常规接口，不构成对任意 Lua 脚本的自动保证。** 备用脚本仍必须遵守玩家视角和正常操作权限，禁止作弊、隐藏信息读取及电脑环境修改；输出为有界打印/返回结果和脚本错误文本，不能由固定字段投影证明公平。上下文选择、输出限制、错误后的确认及超时不能终止引擎等边界，见 [备用 Lua 接口](FALLBACK_LUA.md)。

| `Players` 全体玩家对象 | 当前本地存活人类玩家 | 禁止外部指定 player_id；拒绝观察者不一致、自动演示、多人、热座和编辑器。 |
| 当前玩家单位/城市集合 | 自己的公开属性 | Lua 读属性前检查 owner，Python 再次按 owner 过滤。 |
| `city_status` 城市增长与状况 | 自有城市住房、宜居度、粮食、增长/饥饿估计、幸福度、忠诚度汇总及 GS 供电需求/状态 | 先核对自己的城市集合与所有者，不通过外国 ID 查找城市；不输出外部忠诚度压力源或输电来源。供电仅 GS，按原面板项目分支及一位小数显示；可选字段失败时省略。估计 -1 输出对应 `_active=false`，不伪造零回合。 |
| 自有城市生产工期 | 有限工期或原版的当前无法完成状态 | `GetTurnsLeft()=-1` 转为 `production_indefinite=true`，省略 `production_turns`；有效有限工期为非负整数。未知/失败的估计省略，空队列不读工期；Python 拒绝负工期及“无法完成”与有限工期同时出现。 |
| 曾参与的主要文明集合 | 仅总数；已遇见文明才有明细 | `GetWasEverAliveMajors` 计数；只有询问本方 `HasMet` 所需的槽位 ID 在内部使用。未知文明不读身份/经济/生死状态。 |
| `Map` 地块详细状态 | 已探索且当前可见的格子 | Lua 先检查两个标签再读取；Python 丢弃非可见格子的全部详情。 |
| 村庄、蛮族营地与改良设施 | 当前可见格子的类型、掠夺状态 | `GetImprovementType` 和 `IsImprovementPillaged` 仅在可见性门之后调用；无设施为 `NONE`，缺失/未知 API 则省略；不读取村庄奖励。 |
| 地块区域类型 | 当前可见格子的 `district` | 通过可见性检查后只读该格 `GetDistrictType`；返回 `DISTRICT_*` 或确认无区域的 `NONE`。缺失/不可靠时省略；不枚举所属城市的其他区域，雾中不返回。 |
| 普通地图查询中的已探索迷雾 | 坐标和标签 | 不调用实时内容 getter；不保存服务端历史缓存。 |
| 贸易、间谍原版菜单中的雾内目标 | 仅经菜单资格校验的目的地、任务与路线收益 | 独立菜单证明及字段投影；查询和动作共用菜单条件。见 MENU_PERMISSIONS.md，不改变普通地图过滤。 |
| 原始地块资源及产出 | 不公开 | 不调用原始资源 getter，不返回 tile yields。 |
| 玩家已发现资源 | 类型 | 玩家的资源图层与 `IsResourceVisible` 同时通过；Python 还要求内部可见标记。 |
| `own_resources` 本方战略资源 | 已解锁资源的数量、风云变幻库存/收入/需求 | 静态战略资源定义先经本玩家 `IsResourceVisible(Hash)`，再读名字与自己资源管理器数据；未解锁不查询数值、不返回名称，不扫描地图或外方来源。可选数值失败时省略。 |
| `own_luxuries` 本方奢侈品 | 原版资源总览的本方正数量持有，包括伟商资源 | 只查静态奢侈品类别的本方 `GetResourceAmount(Index)`，正数后才读名称；不按地图频率过滤，不读取地图、其他玩家或来源，不把持有量称为交易上限。核心数量未知则整次查询不可用。 |
| 可见格上的外国单位 | 逐单位已探测者 | 先格可见，再 `IsUnitVisible(unit)`，再读任何单位 getter；Python 还要求 detected 证明与坐标匹配。 |
| 可见外国市中心 | 用户 P02 确认的城市详情 | 重复核对可见性及市中心坐标；不查其他城市或离屏区域坐标。 |
| 远处/隐藏的外国城市与单位 | 不公开完整详情 | 无绕过视野的按 ID 查询入口。贸易、间谍只在复刻菜单筛选时内部枚举城市，失败候选的名字、坐标与数量不返回。 |
| 已遇见主要文明 | 公开身份、金币、科学/文化、军力、分数 | 先 `HasMet` 再读；同原版 UI 的功能门槛、存活状态及显示精度。 |
| 城邦菜单及动作 | 已遇见、存活且可接受影响力的城邦 | 排除主要文明、蛮族、自由城市及无影响力资格对象；宣战只在和平时、议和只在战争时提供，并分别检查原版行动资格，提交时重查。 |
| 外交议程 | 正常外交界面已揭示的议程 | `GetAgendasAndVisibilities` 的每项 Visibility 必须不高于本方情报级别，之后才读真实议程 ID。 |
| 公开胜利进度 | 科技工程/远征、文化游客、宗教传播城市总数/信仰产出、外交点数 | 固定汇总字段、启用胜利类型门槛；不返回隐蔽首都位置、转换文明身份或任意需求数据。 |
| 全局城市距离、忠诚度选址评分 | 不公开 | 无相关查询/顾问功能；避免推断迷雾中的城市。 |
| 玩家科技、市政、生产选项 | 自己正常可选择的选项 | 用原 UI 的合法性判断，不返回引擎失败原因。科技/市政可额外返回本方 `name`、`description`、`boost_description`、`cost`、`progress`、`turns`、`boosted`；可选 getter 不可用时省略字段。 |
| 政策卡菜单与配置 | 当前规则集正常菜单允许的卡牌 | 风云变幻同时要求未被禁止、`CanPolicyBeSlotted` 为真且未过时；基础版/迭起兴衰沿用已解锁且未过时的原版判定。查询和提交共用检查，不用单独的“已解锁”推断黑暗时代政策可用。 |
| 单位/城市及各领域动作 | 注册表中的固定动作/枚举 | 严格参数形状；同一请求核对会话、回合、玩家、归属；正常 UI 请求。详见 COVERAGE_AUDIT.md。 |
| 当前显示 UI | 可见正文、按钮、启用状态 | 只遍历显示中的控件树；响应绑定正文、回调、控件及会话；隐藏队列不读。 |
| 原生模态栈及动态实例弹窗 | 固定已审计上下文内实际显示的模态正文与按钮 | 实例子控件路径不可查时只按固定上下文的真实模态状态发现；逐级检查可见性后只把当前可见模态上下文当独立渲染根。未知模态不读名称/正文/子树，仅报告不可用并停止签发动作令牌。 |
| 通知对象及关闭请求 | 本玩家尚未忽略的通知 | 先核对本地所有者，再要求 `IsDismissed()==false` 才读取正文或提供动作。`FindType` 保留的已关闭对象不返回；检查缺失/异常只省略该条。激活/关闭时重查，关闭仍要求用户可关闭且不阻塞回合，并使用原版 `NotificationManager.Dismiss(playerID,id)`。 |
| 议会、外交和弹窗的非普通回合阶段 | 当前本方真实决策 | 独立 token_scope；对应动作重新验证投票阶段、真实会话或已显示按钮；不能执行普通回合动作。 |
| 自己的失败/终局 | 仅本方结果 | 固定最小状态查询允许检测失败，不读取死后观察者世界，也不发动作令牌。 |
| 移动到未知相邻格 | 普通探索尝试 | 仅检查自身、地图几何及相邻性；不查询目标内容/路径，不传攻击标志，不报告目标合法性结果。 |
| `queue_move` 长程移动目标 | 已探索格的记忆坐标，可在当前迷雾中 | 仅自有可移动陆海单位、正移动力；目标先过边界及 `IsRevealed`，拒绝同格。不读取目标内容、路径或目标合法性结果；单次非攻击正常请求，不自动重试。提交不保证入队、到达或保留原移动计划。 |
| 强制结束回合 / FinishMoves / 设置资源 | 无 | `can_end_turn` 检查活动回合已就绪、消息处理、模态界面、`UI.CanEndTurn`、正常请求接口及通知阻塞；缺少检查能力时不报告可结束。实际结束回合重新验证，不包含作弊 setters。 |
| 日志、原始错误、协议输出 | 无 | 随机请求边界＋本次固定上下文输出筛选；固定错误码；不打印原始响应。 |
| 保存/载入/自动重开/存档解析 | 无 | 手动进入对局；服务不能获取存档中的隐藏世界。 |

## 自动验证覆盖

以下是常规接口的权限与传输验证。任意备用脚本不能沿用这些测试的非干扰结论；其身份前置、一次执行、输出限额和状态失效需要独立验证，不代表已证明脚本内容公平。

- 隐藏世界内容任意改变时，可见输出保持相同。
- 隐藏 getters、原始资源、地块产出和未获授权的外国实体 getters 一旦被读取即抛错。
- 地块可见但逐单位不可见时，连该单位 ID、拥有者和名字都不读取；加入隐藏单位不改变公开输出。
- 普通地图查询中不可见市中心不读取城市详情；菜单例外只放行原版实际提供的字段与任务目标，不放行完整城市详情。
- 未遇见文明的身份和属性改变不影响结果；仅文明总数公开。
- 隐藏议程、未发射远征的旅行数据、对手精确每回合净收入等不可放行字段在验证前就被丢弃，避免通过错误间接探测。
- 可见地块仍不能泄露未发现资源；只允许明确可见的资源类型。
- 游戏切换玩家、同回合加载、回合倒退时，旧会话无法提交动作。
- 非人类、观察者、多人与热座、自动演示、编辑器、缺失必要 API 全部拒绝。
- 外国实体 ID、额外字段、Lua 注入、布尔冒充整数、过期/重放/非 ASCII 令牌被拒绝。
- 请求超时、重连竞态、并发、取消不重复执行动作。
- TCP 分片、超大/损坏帧、其他上下文/全局日志、重复 JSON 被拒绝或丢弃。
- 真实 MCP SDK 客户端完成 stdio 初始化、工具枚举和受限调用。

## 已完成的只读检查与后续场景验收

2026-10-27 已在本机 Steam 单人对局第 1 回合完成连接、自己单位、回合阻塞及领域选项的只读检查；也核对了已加载弹窗的控件方法与固定回调。没有执行本次新增的游戏动作或触发弹窗。此前 2026-10-26 的基础建城、移动、研究、生产、驻扎与结束回合联调记录保留在 README。

自动测试模拟了引擎接口，不能证明某个实际引擎版本的行为。以下清单用于后续独立测试存档中的场景验收和回归，尤其是新动作的实际效果与弹窗队列切换：

1. 开启 Tuner 后连接，确认 InGame 输出前缀、状态发现和安全守卫兼容实际游戏。
2. 读取自己单位/城市，并逐项与正常 UI 比较。
3. 在可见、已探索不可见、未探索三类地块上对照输出。
4. 解锁战略资源前后对照资源显示，确认隐藏资源始终不出现。
5. 普通相邻移动，包括未知目的格：确认不绕过移动规则、不意外攻击、不暴露目标合法性。
6. 读档到同一回合，确认旧观察令牌失效；重新观察后正常恢复。
7. 单位归属变化、回合切换、断线和重连后，旧动作不执行。
8. 生产、研究、建城和正常结束回合：收到提交结果后重新观察确认状态变化。
9. 有政策、宗教、外交、占城、间谍逃跑、文物、献力或议会阻塞时，查询返回原因及当前选择，由对应正常动作解决，不强制推进。
10. 已照亮海域中的潜艇：未发现时隐藏，相邻或侦隐单位发现后显示，探测丢失后再次隐藏；同时验证伪装晋升及间谍。
11. 可见敌城市中心对照人口、城防、宗教、生产、区域与建筑；离开视野后全部详情消失。
12. 对比文明总数和已遇见名单，未知文明身份不会提前显示；提升外交情报等级前后，议程按正常界面揭示。
13. 先打开鼓舞/尤里卡/奇观/结社弹窗，再连接 MCP；普通状态查询自动返回正文与可用按钮，响应后原版显示下一条或恢复游戏。
14. 已读取弹窗被另一个同文确认框替换时，旧回调不能被用于新弹窗；隐藏内容和下一条队列提示不返回。
15. 外交/议会的中途阶段、内嵌确认框及游戏失败须有明确状态，不以“缺少活动回合”为由误判连接失效。

这些实机验收与 [玩家信息规则确认](PLAYER_CONFIRMATIONS.md) 是两件事：玩家确认哪些信息公开后，仍需代码证明满足对应条件。
