# 历史时刻与巨作总览界面

本批补上两个可由正常游戏流程进入的固定界面，沿用 [弹窗协议](POPUP_PROTOCOL.md) 的可见控件读取、按钮有效性检查和正常关闭。它们是 0.3.6 发布之后的工作区增量，尚未写入原发布归档；实机验收另行记录。

| 公共弹窗 ID | 原版上下文 | 唯一新增响应 |
| --- | --- | --- |
| `historic_moments` | `HistoricMoments` | 可见且启用的 `Controls.Close` → `OnClose`，原版负责从弹窗队列退出 |
| `great_works_overview` | `GreatWorksOverview` | 可见且启用的 `Controls.ModalScreenClose` → `OnHideScreen`，保留原版关闭与事件通知 |

历史时刻可以因本方历史通知被激活而显示，也有满足兴趣等级门槛的自动显示分支。该上下文打开时会移到 `/InGame/Screens`，因此固定路径同时覆盖该位置及资料片加载的 `AdditionalUserInterfaces` 位置，保留 `.xml` 名称变体。巨作总览位于 `/InGame/Screens`；已有巨作展示界面的“查看巨作”按钮会打开它。本批使这一跳转后的界面可被下次观察识别、读取和正常关闭。

读取仅遍历当前显示界面的可见控件文本，不调用历史管理器、不枚举历史数据库、不读取待显示事件队列，也不主动打开或滚动这些界面。隐藏界面及隐藏控件子树不读正文、子控件或回调。巨作调配继续使用已有 `great_works`／`move_great_work` 接口，新增界面只提供关闭，不返回任意控件执行器。

正常打开／关闭事件只使旧按钮失效，不采集事件参数。其他原生模态窗口存在时，底层关闭按钮不会取得操作权限。关闭请求之后必须再次观察；提交成功不等于已经关闭，也不证明后续弹窗队列已空。
