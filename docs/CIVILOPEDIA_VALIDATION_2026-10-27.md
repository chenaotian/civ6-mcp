# 0.4.3 官方简中文明百科验证记录

本批按用户确认，采用官方简中文明百科作为主要规则资料，保留原三本 PDF 作显式参考。默认 `query_manual` 不自动混用繁中或英文。当前游戏继续保持原状，本批未调用真实游戏观察或动作。

## 来源与范围

从本机 Steam 游戏安装目录中的静态官方 XML 提取 `zh_Hans_CN` 文本，按风云变幻采用的本体、迭起兴衰扩展及风云变幻修订顺序整理；不读取存档、日志或运行中数据库。准备脚本检查两个资料片的 modinfo 组件归属，只接受已支持的 XML 操作，不执行 SQL 或 Lua。

- 最终索引：2182 个条目，9 个来源文件，未展开占位符条目数为 0。
- 索引 SHA-256：`40a1f968fd55d8e95a5b46765ebd03d45120175c5707b0052caa682967f1fe11`。
- 按 `Expansion2_RemoveData.xml` 的 `CivilopediaPages` 记录排除 `DIPLO_10`、`TRADE_6`、`COMBAT_11`，过滤全部章节及衍生实体说明。
- 尤里卡 `SCIENCE_3` 的官方旧文仍提到研究协议。保留官方正文，用独立 `annotations` 字段说明版本差异；搜索、全文和可读文档均显示项目注记。
- 另覆盖四个不使用通常 PAGE 标签格式的官方间谍历史章节。

输出包含 JSON 索引、SHA-256 清单及 [可读简中文明百科](../manuals/civilopedia_zh_Hans_CN.md)。原文来源相对路径和本地化标签随条目保留；这些路径仅是来源标识，运行时不会据此读取其他文件。

这是官方静态文字的整理索引，不是完整重建当前游戏百科。安装文件可能保留旧实体的历史介绍；动态图表、数值修正、属性表及脚本生成说明不完整包含。当前玩家能看到的菜单和提示、正常引擎资格检查优先。

## 验证结果

完整离线测试：

```text
python -m pytest -q --tb=short -o faulthandler_timeout=45
3567 passed, 1 skipped, 50 subtests passed in 34.32s
```

跳过项是 Windows 无符号链接创建权限的既有测试。测试覆盖 XML 覆盖顺序、页面删除、原文注记、文件和索引边界、篡改检测、搜索排序、长文续读、语言选择、非法参数及查询不消耗游戏观察令牌。现有游戏动作和备用 Lua 的离线回归同批通过。

使用本机正式资料的检查：

- 中文百科和三个 PDF 来源均为 `ready`。
- 总督、忠诚度、电力、世界议会、洪水、外交胜利、尤里卡、潜艇、贸易路线、科技、不满等 11 个关键词均命中简中条目；默认结果没有 PDF 内容。
- 搜索“潜艇”优先返回潜艇游戏说明，再显示历史背景及相关单位；显式历史查询仍可优先找到历史。
- 三个被删除的页面不在索引；尤里卡正文与项目注记分别保留。
- 真实 SDK stdio 子进程验证 `query_manual` 默认来源为 `civilopedia`，简中搜索、按条目读取及显式风云变幻 PDF 第 6 页均成功；会话历史保持为空。
- MCP 工具仍为 13 个，51 类游戏查询、84 种常规动作不变。查询不会授予当前对局的隐藏信息权限。
- `uv lock --check --offline` 通过，无新增运行依赖。

初次资料检查脚本将 GRIEVANCES 的标题写成“怨恨”，实际官方简中条目名为“不满”；已更正检查关键词后通过，未改写官方标题或正文。

## 交付与复现

重新启动 MCP 进程加载 0.4.3 后，空查询可查看四个来源的可用状态。关键词及 `entry_id` 默认查简中百科；只有显式选择 PDF 来源或 `all` 才会返回原 PDF 语言。

中文准备器只依赖 Python 标准库：

```powershell
python scripts/prepare_civilopedia.py --game-root "F:\SteamLibrary\steamapps\common\Sid Meier's Civilization VI"
```

安装文件更新后可重新准备。新的生成时间会改变索引校验值，因此本记录的哈希只对应本次快照。用户自备的官方文本和 PDF 位于 `manuals/`，不进入 wheel/sdist，也不当作本项目 MIT 代码重新授权。发布包包含查询实现、准备脚本和使用说明；移到其他机器需重新准备资料。
