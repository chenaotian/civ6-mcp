# 参考项目对照：外交与探索

日期：2026-10-27。参考 `lmwilki/civ6-mcp` 的 `dd2019056371b92ea4854e879ddf05a8cad95e8a`，特别是 `src/civ_mcp/lua/diplomacy.py`、`lua/victory.py`、`lua/map.py`。这里记录能力对应关系，不把参考代码视为玩家权限依据。

## 本批新增

`get_diplomacy()` 的已遇见、存活且非本方文明可带 `relationship`：

- `state` / `state_name`：对方对本方的公开关系。通过 `GameInfo.DiplomaticStates[index].StateType` 映射，不硬编码数值顺序。
- `modifiers`：原版外交关系页实际提供的非零分数和文本，分数保留界面两位精度。未知原因保留原版未知文本，不反查隐藏议程；人类玩家不读取计算情绪。
- `access_level` / `access_name`、有正负方向的 `grievances`。
- 已派使团／大使馆、防御协定、双向开放边界、研究协定和共同战争标记。研究协定只给布尔值，不输出对方科技标识；不扫描第三方关系。
- `allied`、同盟类型／名称／等级／剩余回合及非满级时的点数。点数使用原版倍率，满级不读隐藏的点数栏；无同盟、缺接口与数值为零分别处理。

上述字段是可选的；缺失不是零或否。Python 再要求同一本方观察者、同一已遇见目标和原版面板证明，丢弃任意额外字段。

玩家权限依据是已安装的 Firaxis 界面源码：

`inspect_game("exploration_frontier", {"offset": 0})` 新增分页探索边缘：仅从本玩家的已探索标签，结合原版六边形相邻坐标，找出邻接未探索区域的已探索格。每页最多检查 512 格，按返回的 `next_offset` 继续，`-1` 表示结束。支持水平地图环绕；雾中只给坐标和可见标签，不读取地形、资源、单位、归属或任何评分。这是探索方向候选，不代表可抵达、安全或适合建城。不同页是独立的新观察，不能当成跨回合静态快照。

## 已有等价能力

主动外交、友谊、各类宣战、和平、同盟和联合战争交易由 `diplomacy_actions`、`deal_options`、`deal_state`、`war_deal_options` 与对应动作完成。无需新增另一套 `propose_trade` 参数解析器。已有 `deal_equalize` 使用真正可见的原版平衡交易按钮，且需匹配完整报价；不能充当任意隐藏 AI 估值查询。

世界议会已有单次 `congress_ballot`，先校验整张选票、公开目标和外交支持总成本再提交，并提供紧急会议和结果确认。不是参考旧实现只设置本地选票却没有提交的问题。已有城邦使者、宗主竞争、奖励、本方任务、征召与和平战争动作。

公开胜利汇总已包括已遇见文明的科技项目里程碑、公开游客总量、信教城市总量和外交胜利点。本批另由内政模块新增本方科学胜利细节。

## 未照搬的实现

参考外交查询会枚举未知文明对象、在 revealed 城市读取实时人口／忠诚／城防，并统计对手全部城市；参考胜利统计还扫描外国城市区域、计算全体文明人口和经济排名。本项目不复制这些读取路径。它们与用户要求的当前玩家权限边界不一致。公开关系数据采用原版面板接口；城市实时状态继续要求当前可见；未知文明只有总数。

参考战略地图／建城顾问中的全世界城市距离、雾中实时资源和人工评分不照搬。替代路径是本批的原版 `unit_recommendations`、`exploration_frontier`，已有 `observe_area`、本方资源库存、城市选址与原版区域预览，由 AI 根据合法观察作决策。

## 测试边界

新测试实际执行生成 Lua，使用未遇见、已灭亡、隐藏人类情绪、零分隐藏文本、未解锁资源和地块内容陷阱；另验证 Python 二次证明、分页范围、重复坐标、地图环绕、错误数值和孤儿字段过滤。全量结果见总报告。本批遵照用户要求不连接当前游戏；新字段的实机验证留待全新对局。
